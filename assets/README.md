# Logo source files

Exported from Figma. The wordmark reads "nline Na Ba?": the power-button
symbol supplies the "O".

| File | What it is |
|---|---|
| `wordmark.svg` | "nline Na Ba?" in #0E2520 |
| `symbol.svg` | The power-button "O" with status dot, in #087F5B |

The composed logo (symbol sized to the wordmark's cap height, baseline-aligned),
its dark-mode variant and the square icon are in `docs/brand/`. The site uses
them in `src/components/logo.tsx`, `src/app/icon.svg` and `src/app/apple-icon.png`.
